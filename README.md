## 🛠️ Projeto principal: PCCT — Monitoramento de Laboratórios

Sistema de monitoramento de desempenho de computadores nos 3 laboratórios de informática do IFAM Campus Coari, cobrindo **60 máquinas Dell OptiPlex 7080** com Windows 11.

- **Zabbix 7.4** com template próprio (itens, triggers e regras de descoberta automática)
- **Grafana** com dashboards por laboratório e por host
- **Proxmox VE** hospedando a máquina virtual do servidor (Linux Mint, MariaDB, Nginx)
- **Alertas por e-mail** (SMTP) configurados e validados com alertas reais
- Scripts em **PowerShell** e **Bash** para coleta de métricas e atualização de DNS/hosts
- Projeto de 250 horas, documentado em relatório técnico de 74 páginas

   📂 Código e documentação: [pcct-zabbix-lab-monitoring](https://github.com/Efraimxx7/pcct-zabbix-lab-monitoring)
